## C-R1 — v2.3.0 unlisted build

### 1. Automated preflight

```bash
pnpm release:preflight
```

Writes `artifacts/release-preflight-report.txt`. All steps must pass before tagging.

Optional full CI parity:

```bash
pnpm test:ci
```

### 2. Package zips

```bash
pnpm release:chrome    # releases/signallens-chrome-core-v2.3.0.zip
pnpm release:firefox   # releases/signallens-firefox-core-v2.3.0.zip
```

### 3. Store submit (unlisted)

| Store | Zip | Listing | Privacy |
|-------|-----|---------|---------|
| Chrome | `signallens-chrome-core-v2.3.0.zip` | [`listing-chrome.md`](../../store/listing-chrome.md) | `store-meta.json` URL |
| Firefox | `signallens-firefox-core-v2.3.0.zip` | [`listing-firefox.md`](../../store/listing-firefox.md) | same |

```bash
pnpm store:verify:scope
```

### 4. Git tag (after upload)

```bash
git tag v2.3.0
git push origin v2.3.0
```

Record Chrome item ID + AMO slug in team notes.

## C-R7 — v3.0.0 listed (later)
