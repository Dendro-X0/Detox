## v2.2.0 deliverables

### 1. Production mod signing

```bash
pnpm signing:generate          # prod-private.pem + prod-public.pem (gitignored)
pnpm signing:apply-anchor -- --pem packages/signing/prod-public.pem
pnpm signing:resign -- --private-key packages/signing/prod-private.pem
pnpm release:verify            # should show no dev-key warning
```

- [x] Generate Ed25519 keypair locally (`pnpm signing:generate`)
- [x] **Do not** commit private key (see `.gitignore`)
- [x] Update [`src/core/mods/trust-anchor.ts`](../../src/core/mods/trust-anchor.ts) via `pnpm signing:apply-anchor`
- [x] Re-sign official mod unlock packages (`pnpm signing:resign`)
- [x] Confirm `pnpm release:verify` no longer warns about dev trust anchor

See [`packages/signing/README.md`](../../packages/signing/README.md).

### 2. Privacy policy URL

Canonical URL: [`store/store-meta.json`](../../store/store-meta.json) → `privacyPolicyUrl`

- [x] Options → Privacy tab shows **Privacy policy** link (wired from `store-meta.json`)
- [x] Run `pnpm store:verify` locally; `pnpm store:verify:online` before store submit
- [ ] Paste same URL in Chrome/Firefox store privacy fields

### 3. Store assets

- [ ] Screenshots per [`store/SCREENSHOTS.md`](../../store/SCREENSHOTS.md) and [`listing-chrome.md`](../../store/listing-chrome.md)

### 4. Build and submit

- [x] Bump version to `2.2.0` in `package.json`, `src/manifest.json`, `manifest-firefox.json`
- [ ] `pnpm release:chrome` → `releases/signallens-chrome-core-v2.2.0.zip`
- [ ] `pnpm release:firefox` → `releases/signallens-firefox-core-v2.2.0.zip`
- [ ] Submit **unlisted** on both stores ([`store-release.md`](../guides/store-release.md))
- [ ] Tag `v2.2.0` after upload IDs recorded

### 5. Out of scope for v2.2.0

- Public listing (wait until v2.3.x refinement gate before v3.0.0)
- ONNX / full-profile default-on
- Wizard authenticity opt-in step (v2.3.x)
