# UI locales

SignalLens UI copy lives in JSON locale templates under `src/i18n/locales/`. The onboarding wizard, options dashboard, toolbar popup, and content-script overlays read strings from the active template. **English** (`en`) and **German** (`de`) ship today.

## Localized surfaces

| Surface | Wrapped in `LocaleProvider` |
|---------|------------------------------|
| Onboarding wizard | `OptionsApp` |
| Options dashboard | `OptionsApp` |
| Toolbar popup | `main.tsx` |
| Authenticity side panel | `sidepanel-main.tsx` |
| Filtered block tooltips + authenticity badge | content script (`runtime-locale.ts`) |

Language preference is stored as `preferredLocale`. Users can change it on the wizard **Language** step or under **Overview → Interface language** in the dashboard.

Mod names and descriptions are localized via `mods.<id>.*` keys in locale JSON (see `src/i18n/mod-catalog.ts`). The English strings in `mod-manifest.ts` remain as documentation fallbacks.

Background pipelines store user-visible system text as `i18n:<key>` messages; React surfaces translate them with `localizeMessage()` / `localizeCompoundMessage()`.

## Add a new language

1. Copy `src/i18n/locales/en.json` to `src/i18n/locales/<id>.json` (ISO 639-1 code, e.g. `de.json`), or maintain overrides in `<id>.overrides.json` and run `pnpm locale:de` for German.
2. Translate all values; keep keys and structure identical.
3. Register the locale in `src/i18n/registry.ts`:
   - Import the JSON bundle.
   - Add to `LOCALE_BUNDLES`.
   - Add a row to `LOCALE_CATALOG`.
4. Extend `LocaleId` in `src/i18n/types.ts`.
5. Run `pnpm test:scanner` (includes `tests/i18n/locale.spec.ts`).

Users pick their language on the **Language** wizard step. The choice is stored as `preferredLocale` in extension storage.

## Runtime API

| Module | Purpose |
|--------|---------|
| `src/i18n/locales/*.json` | Translated strings |
| `src/i18n/registry.ts` | Available locales + bundle lookup |
| `src/i18n/translate.ts` | `translate(bundle, key, values?)` |
| `src/i18n/locale-store.ts` | Load/save `preferredLocale` |
| `src/i18n/localize.ts` | `i18nMessage()`, `localizeMessage()` for background-stored strings |
| `src/i18n/mod-catalog.ts` | Localized mod library labels |
| `src/i18n/runtime-locale.ts` | Content-script locale load + `runtimeTranslate()` |

Wrap React trees that need translations in `<LocaleProvider>`. Content scripts call `initRuntimeLocale()` at startup.
